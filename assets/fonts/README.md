# NanumSquare

Korean typeface for the site, matching the legacy IMweb design. Weights 400
(Regular) and 800 (ExtraBold) — 800 is what the home hero headline uses.

These files exist to be **uploaded into Super** (Design → Typography → upload),
not to be served from this repo. Nothing links to them by URL.

| File | Weight | Size |
| --- | --- | --- |
| `NanumSquareR.woff2` / `.woff` / `.ttf` | 400 | 191K / 274K / 707K |
| `NanumSquareEB.woff2` / `.woff` / `.ttf` | 800 | 193K / 273K / 710K |

Try `.woff2` in Super's uploader first; fall back to `.woff`, then `.ttf`, since
the accepted formats are not documented.

Provenance: `.woff` and `.ttf` pulled from the `moonspam/NanumSquare` webfont
mirror on 2026-08-25; verified genuine by their internal name records
(`나눔스퀘어`, `나눔스퀘어 ExtraBold`) and `usWeightClass` 400 / 800. The `.woff2`
files were converted from those `.ttf` here with fontTools.

NanumSquare is Naver's typeface, published free for use and redistribution
including commercial use. That mirror carries no LICENSE file; for an
authoritative copy and the current license text, go to Naver's own font page
rather than the mirror.
